# HIDROLAB V7.0 — UI Modern

Modernización visual sin modificar fórmulas ni lógica de cálculo.

## Cambios globales
- Modo claro / oscuro persistente.
- Navegación con glassmorphism.
- Sistema visual "Scientific Control Center".
- Tipografía monoespaciada para resultados técnicos.
- Sliders con progreso visual.
- Microinteracciones y ripple en botones.
- Entrada de elementos con fade/slide discreto.
- Iconografía SVG de línea fina en lugar de emojis.
- Tarjetas con hover, elevación y acento por categoría.
- Ajustes de tablas, inputs y paneles para dark mode.

## Inicio
- Hero completamente renovado.
- Preview interactivo del Solar Studio.
- Bento Grid para presentar las áreas técnicas.
- Acceso prioritario al simulador Solar 3D.

## Calculadoras
- Catálogo con buscador en tiempo real.
- Navegación lateral por categorías.
- Tarjetas modernizadas e iconografía SVG.

## Arquitectura
Se conserva HTML + CSS + JavaScript + Three.js existente. No se migra a React/Tailwind
para evitar introducir riesgo innecesario en los módulos técnicos ya validados.
