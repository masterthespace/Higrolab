# HIDROLAB V6.3.5 — Identificación visual de fachadas

- Etiquetas F1, F2, F3… visibles en Modelo 3D y Análisis Solar.
- Cada etiqueta muestra orientación resumida y azimut.
- La fachada seleccionada resalta su etiqueta.
- Las etiquetas se reposicionan con la cámara y se ocultan al salir del viewport.
- La vista Planta incorpora F1, F2, F3… sobre cada tramo del perímetro.
- El informe PDF incorpora un esquema específico con Norte, F#, orientación y azimut.
- La tabla de asoleamiento hace referencia directa a dicho esquema.
