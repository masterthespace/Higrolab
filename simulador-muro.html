06 · Trazabilidad técnica

Qué representa cada resultado

MÉTODO TÉRMICOR, Rt y U

Para capas homogéneas se usa R=e/λ y U=1/Rt con resistencias superficiales. Para entramados, HIDROLAB marca expresamente la corrección como estimación simplificada.

FÍSICOPérdida térmica

Q̇ = U · A · |Ti − Te|. Es una potencia instantánea en régimen estacionario; no equivale a consumo mensual.

DATOS DE MATERIALESλ de biblioteca

Los valores con etiqueta “orientativo” sirven para simulación. Para memoria técnica debe utilizarse el valor respaldado por producto, ensayo, listado oficial o fuente normativa aplicable.

COMPARACIÓN OGUCU máxima / Rt mínima

La comparación opcional evalúa solo el parámetro térmico del muro para la zona seleccionada. No sustituye la acreditación reglamentaria completa.
