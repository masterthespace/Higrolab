# HIDROLAB V8.7.2 — Mapa y navegación

- El botón Atrás queda integrado en la barra superior de cada herramienta.
- Se elimina el botón flotante entre el header y el contenido.
- Home / Análisis solar interactivo incorpora Región → Comuna.
- Se reutiliza la base local de comunas de Chile ya existente.
- La comuna carga coordenadas de referencia.
- Se pueden ingresar coordenadas manuales.
- Google Maps se muestra dentro del recuadro de análisis solar.
- Se incorpora acceso para abrir la ubicación en Google Maps.
- Solar Studio recibe latitud, longitud, región y comuna desde la Home.
- Se actualiza CSP de Vercel para permitir el iframe de Google Maps.
- No se modifican fórmulas ni cálculos físicos.
