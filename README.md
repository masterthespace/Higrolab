# HigroLab

Sitio web estático para evaluar riesgo de condensación y alojar una zona educativa con videos.

## Secciones
- `/` Inicio
- `/calculadora/` Calculadora y matriz de riesgo
- `/interactiva/` Galería para videos de YouTube

## Tecnología
HTML, CSS y JavaScript puro. No requiere npm, framework, backend ni base de datos.

## Publicación
Este repositorio está preparado para importarse directamente en Vercel desde GitHub.
