# HIDROLAB V6.3.11 — Eliminar imagen de referencia

Se agrega un botón independiente en `REFERENCIA SATELITAL`:

**Eliminar imagen de fondo**

Este botón:
- elimina únicamente el JPG/PNG cargado;
- conserva la planta dibujada;
- conserva la calibración métrica;
- conserva el Norte definido;
- conserva la geometría 3D;
- conserva el análisis solar;
- permite cargar posteriormente otra imagen de referencia.

El botón `Nuevo` mantiene su comportamiento separado.
También se libera la URL temporal de la imagen para evitar retener memoria innecesariamente.
